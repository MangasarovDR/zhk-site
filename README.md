# Тили-бом — ЖК глазами жильцов

Статические страницы по жилым комплексам, собранные из того, что реально пишут жильцы в своих Telegram-чатах — а не из рекламных описаний застройщика. Каждая страница ЖК: агрегированная тональность обсуждений, характерные темы и цитаты, обновляется ежедневным пересборщиком.

## Как это устроено

- **Сбор** — Telegram-бот (`tools/bot.py`) слушает чаты жителей ЖК.
- **Тональность** — LLM-классификация сообщений по темам и тону (`tools/tone_llm.py`, `tools/tone_model.py`).
- **Гео и данные о ЖК** — сверка с ЕРЗ и геокодирование адресов (`tools/zhk_data.py`).
- **Сборка сайта** — статическая генерация страниц по шаблонам Jinja (`tools/build_site.py`, `templates/`).
- **Ежедневный цикл** — пересборка, индексация в поисковиках через IndexNow (`tools/daily.py`, `tools/indexnow.py`).
- **Контроль качества** — автоматические проверки датасета и вёрстки перед публикацией (`tools/check_site.py`, `tools/check_sort.js`).

## Стек

Python, Jinja2, SQLite, Telegram Bot API, ванильный JS на фронте.

## Что не в репозитории

Данные (`data/`) — это живой продукт с реальными сообщениями жителей, не код; исключены из публикации вместе с ключами и конфигурацией. Здесь только инструменты, которыми это построено.
